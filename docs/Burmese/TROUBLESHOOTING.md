# Troubleshooting (မြန်မာ)

ဤ စီမံကိန်းကို လေ့လာရင်းနှင့် အလုပ်လုပ်ရင်း ကြုံတွေ့ရနိုင်သည့် အတွေ့ရများသော ပြဿနာများ ဖြစ်သည်။ အကြောင်းအရာ တစ်ခုစီတွင် ရောဂါလက္ခဏာ (Symptom)၊ ဖြစ်နိုင်ခြေရှိသော အကြောင်းရင်း (Cause) နှင့် ဖြေရှင်းနည်း (Fix) တို့ကို ဖော်ပြထားသည်။

## တပ်ဆင်မှုဆိုင်ရာ ပြဿနာများ (Setup Issues)

### "bun: command not found"

**ရောဂါလက္ခဏာ** - Shell က `bun` command ကို ရှာမတွေ့ပါ။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Bun တပ်ဆင်ထားခြင်း မရှိပါ** - [https://bun.sh](https://bun.sh) မှ ဒေါင်းလုဒ်ဆွဲ၍ တပ်ဆင်ပါ။
2. **Bun ကို PATH တွင် ထည့်သွင်းထားခြင်း မရှိပါ** - Terminal ကို ပြန်စတင်ပါ သို့မဟုတ် Bun ကို သင်၏ PATH သို့ ပေါင်းထည့်ပါ။
```bash
export PATH="$HOME/.bun/bin:$PATH"

```


3. **Shell မှားယွင်းနေပါသည်** - Bun ထောက်ပံ့ပေးသော Shell ကို အသုံးပြုပါ (PowerShell 7+, bash, zsh, fish)။

### `mtc` ကို Run သည့်အခါ "Permission denied" ဖြစ်နေခြင်း

**ရောဂါလက္ခဏာ** - Binary ဖိုင် ရှိသော်လည်း Execute ပြုလုပ်၍ မရပါ။

**ဖြေရှင်းနည်း** -

1. Binary ဖိုင်တွင် Execute ခွင့်ပြုချက်များ ရှိမရှိ သေချာပါစေ - `chmod +x bin/mtc`
2. Windows တွင် PowerShell Execution Policy က Scripts များ Run ခွင့် ပြုမပြု သေချာပါစေ။

### Build ပြုလုပ်ပြီးနောက် "Cannot find module" အမှားများ ပြသခြင်း

**ရောဂါလက္ခဏာ** - `mtc` သည် Module ရှာမတွေ့သည့် အမှားများဖြင့် ပျက်စီး (Crash) သွားသည်။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Dependencies များ တပ်ဆင်ထားခြင်း မရှိပါ** - Project root တွင် `bun install` ကို Run ပါ။
2. **Build မအောင်မြင်ပါ** - အမှားများအတွက် `bun run build` output ကို စစ်ဆေးပါ။
3. **Working directory မှားယွင်းနေပါသည်** - `mtc` ကို Project root မှ Run ပါ။

## TUI ဆိုင်ရာ ပြဿနာများ (TUI Issues)

### TUI က တိကျစွာ မပေါ်ဘဲ စာသားများ ပျက်ယွင်းနေခြင်း

**ရောဂါလက္ခဏာ** - Terminal UI သည် ပျက်စီးနေပုံပေါ်ခြင်း၊ စာလုံးများ မညီမညာဖြစ်ခြင်း သို့မဟုတ် အရောင်များ မှားယွင်းနေခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Terminal သေးငယ်လွန်းနေပါသည်** - အနည်းဆုံး 80x24 ရောက်အောင် အရွယ်အစား ပြောင်းပါ။
2. **ထောက်ပံ့မထားသော Terminal ဖြစ်နေပါသည်** - ခေတ်မီသော Terminal ကို အသုံးပြုပါ (iTerm2, Windows Terminal, GNOME Terminal)။
3. **ကိုက်ညီမှုမရှိသော Font ဖြစ်နေပါသည်** - Unicode ထောက်ပံ့မှု ကောင်းမွန်သော Font သို့ ပြောင်းလဲပါ။

### TUI အလုပ်မလုပ်တော့ဘဲ ရပ်တန့် (Freeze) သွားခြင်း

**ရောဂါလက္ခဏာ** - TUI က အချက်အလက်သစ်များ မပြတော့ဘဲ သို့မဟုတ် Input များကို လက်မခံတော့ပါ။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **LLM provider တုံ့ပြန်ချိန် လွန်သွားခြင်း (Timeout)** - သင်၏ အင်တာနက် ချိတ်ဆက်မှုနှင့် Provider အခြေအနေကို စစ်ဆေးပါ။
2. **နောက်ကွယ် လုပ်ဆောင်ချက်က ပိတ်ဆို့နေခြင်း** - Tool တစ်ခုခု ငြိမ်သွားခြင်း ဖြစ်နိုင်သည်။ ဖျက်သိမ်းရန် `Ctrl+C` ကို နှိပ်ပါ။
3. **Terminal အခြေအနေ ပျက်စီးသွားခြင်း** - TUI မှ ထွက်၍ ပြန်စတင်ပါ။

### Agent က မက်ဆေ့ဂျ်များကို ပြန်လည်မတုံ့ပြန်ခြင်း

**ရောဂါလက္ခဏာ** - စာသား ရိုက်ထည့်သော်လည်း မည်သည့် တုံ့ပြန်ချက်မှ မရရှိပါ။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **LLM provider ပြင်ဆင်သတ်မှတ်ထားခြင်း မရှိပါ** - စစ်ဆေးရန် `mtc llm status` ကို Run ပါ။
2. **API key မမှန်ကန်ပါ** - သင်၏ Key ကို `mtc llm set-provider` ဖြင့် စိစစ်ပါ။
3. **ကွန်ရက် ပြဿနာဖြစ်နေပါသည်** - LLM API endpoint သို့ ချိတ်ဆက်နိုင်မှုကို စစ်ဆေးပါ။
4. **Rate limited ဖြစ်နေပါသည်** - ခဏစောင့်ဆိုင်းပြီး ထပ်မံစမ်းသပ်ပါ။

## LLM နှင့် Provider ဆိုင်ရာ ပြဿနာများ (LLM and Provider Issues)

### LLM provider ထံမှ "401 Unauthorized" ထွက်ပေါ်ခြင်း

**ရောဂါလက္ခဏာ** - LLM ခေါ်ယူမှုများက 401 errors များနှင့် မအောင်မြင်ပါ။

**ဖြေရှင်းနည်း** -

1. API key မှန်ကန်ကြောင်း စိစစ်ပါ - `mtc llm status`
2. Key သက်တမ်းမကုန်သေးကြောင်း သို့မဟုတ် ရုပ်သိမ်းမခံရသေးကြောင်း စစ်ဆေးပါ။
3. စံမဟုတ်သော Endpoint ကို အသုံးပြုပါက `AI_BASE_URL` မှန်ကန်ကြောင်း သေချာပါစေ။

### "429 Too Many Requests" ဖြစ်နေခြင်း

**ရောဂါလက္ခဏာ** - LLM provider မှ Rate limited ပြုလုပ်လိုက်ခြင်း။

**ဖြေရှင်းနည်း** -

1. Rate limit ပြန်လည်စတင်သည်အထိ စောင့်ပါ။
2. အခြား Provider တစ်ခုသို့ ယာယီ ပြောင်းလဲအသုံးပြုပါ။
3. ရရှိနိုင်ပါက Request caching ကို ဖွင့်ပါ။

### တုံ့ပြန်ချက်များ နှေးကွေးခြင်း သို့မဟုတ် Timeout ဖြစ်ခြင်း

**ရောဂါလက္ခဏာ** - LLM တုံ့ပြန်ချက်များ ကြာမြင့်လွန်းခြင်း သို့မဟုတ် လုံးဝ ရောက်မလာခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **ကွန်ရက် နှောင့်နှေးမှု (Latency)** - API endpoint သို့ သင်၏ ချိတ်ဆက်မှုကို စစ်ဆေးပါ။
2. **Model ဝန်ပိနေခြင်း** - အခြား Model သို့မဟုတ် Provider တစ်ခုကို စမ်းကြည့်ပါ။
3. **Context window ကြီးမားနေခြင်း** - စကားပြော မှတ်တမ်း ရှည်လျားပါက Latency မြင့်တက်စေပါသည်။

## Tool နှင့် ခွင့်ပြုချက်ဆိုင်ရာ ပြဿနာများ (Tool and Permission Issues)

### "Permission denied" ဖြင့် Tool မောင်းနှင်မှု မအောင်မြင်ခြင်း

**ရောဂါလက္ခဏာ** - Agent က Tool တစ်ခုကို အသုံးပြုရန် ကြိုးပမ်းသော်လည်း ပိတ်ဆို့ခံရခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Agent ခွင့်ပြုချက်များ တင်းကြပ်လွန်းနေပါသည်** - `.mtc/agents/*.md` ပါ Agent ၏ Frontmatter ကို စစ်ဆေးပါ။
2. **Global ခွင့်ပြုချက် စည်းမျဉ်းများ** - `~/.config/mtc/permissions.json` ကို စစ်ဆေးပါ။
3. **အသုံးပြုသူက Tool ကို ငြင်းပယ်ခဲ့သည်** - ခွင့်ပြုချက် တောင်းခံမှု မြင်တွေ့ပါက သင် လက်ခံခဲ့ကြောင်း သေချာပါစေ။

### `run_bash` မှ မမျှော်လင့်ထားသော Output များ ထွက်ပေါ်လာခြင်း

**ရောဂါလက္ခဏာ** - Bash commands များက Errors များ သို့မဟုတ် မမျှော်လင့်ထားသော ရလဒ်များ ထွက်ပေါ်စေခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Working directory မှားယွင်းနေပါသည်** - Agent ၏ လက်ရှိ Directory ကို စစ်ဆေးပါ။
2. **Dependencies များ မရှိပါ** - Command ၏ Dependencies များ တပ်ဆင်ထားကြောင်း သေချာပါစေ။
3. **Shell syntax** - Agent သည် `sh`-compatible syntax ကို အသုံးပြုသည်။

### `edit_file` မှ မမှန်ကန်သော Patches များ ထုတ်လုပ်ခြင်း

**ရောဂါလက္ခဏာ** - ဖိုင်ပြင်ဆင်မှုများ မအောင်မြင်ပါ သို့မဟုတ် မှားယွင်းသော အကြောင်းအရာများကို ပြင်ဆင်မိခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **ဖိုင်အကြောင်းအရာ ဟောင်းနွမ်းနေခြင်း** - ဖိုင်ကို ဖတ်ပြီးနောက်ပိုင်း ပြောင်းလဲသွားခြင်း ဖြစ်နိုင်သည်။
2. **မမှန်ကန်သော ရှာဖွေမှု စာသား** - `old` သည် တိကျစွာ ကိုက်ညီကြောင်း သေချာပါစေ။
3. **ထပ်မံတွေ့ရှိမှု အများအပြား ရှိနေခြင်း** - `old` သည် အကြိမ်ကြိမ် ပေါ်နေပါက Context ကို ပိုမို တိကျစွာ သတ်မှတ်ပေးပါ။

## MCP ဆိုင်ရာ ပြဿနာများ (MCP Issues)

### MCP Server စတင်ရန် မအောင်မြင်ခြင်း

**ရောဂါလက္ခဏာ** - MCP server က Disconnected သို့မဟုတ် Failed ဟု ပြသနေခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Command ရှာမတွေ့ပါ** - MCP server binary ကို တပ်ဆင်ထားကြောင်းနှင့် PATH တွင် ရှိကြောင်း သေချာပါစေ။
2. **Dependencies များ မရှိပါ** - MCP server ၏ တပ်ဆင်မှု Command ကို Run ပါ။
3. **Wrong args** - မှန်ကန်သော Command နှင့် Arguments များအတွက် `.mtc/mcp.json` ကို စစ်ဆေးပါ။
4. **Environment variables** - လိုအပ်သော Env vars များ သတ်မှတ်ထားကြောင်း သေချာပါစေ။

### MCP Tools များ Agent တွင် ပေါ်မလာခြင်း

**ရောဂါလက္ခဏာ** - Agent က MCP tools များကို မမြင်နိုင်ဘဲ သို့မဟုတ် အသုံးပြု၍ မရဘဲ ဖြစ်နေခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Server ကို စတင်ထားခြင်း မရှိပါ** - MCP config ထည့်သွင်းပြီးနောက် `mtc` ကို ပြန်စတင်ပါ။
2. **Server က Tools စာရင်း မထုတ်ပေးနိုင်ပါ** - MCP server ၏ Logs များကို စစ်ဆေးပါ။

## Session နှင့် သိမ်းဆည်းမှုဆိုင်ရာ ပြဿနာများ (Session and Persistence Issues)

### ပြန်စတင်ပြီးနောက် Session မှတ်တမ်းများ ပျောက်ဆုံးသွားခြင်း

**ရောဂါလက္ခဏာ** - `mtc` ကို ပြန်စတင်ပြီးနောက် ယခင် စကားပြောဆိုမှုများ ပေါ်မလာတော့ခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **SQLite database ဖျက်ဆီးခံရခြင်း** - `~/.config/mtc/sessions.db` ရှိမရှိ စစ်ဆေးပါ။
2. **Config directory မှားယွင်းနေခြင်း** - `HOME` / `USERPROFILE` မှန်ကန်စွာ သတ်မှတ်ထားကြောင်း သေချာပါစေ။
3. **ခွင့်ပြုချက် ငြင်းပယ်ခံရခြင်း** - Config directory ပေါ်ရှိ File permissions များကို စစ်ဆေးပါ။

### File patches များကို မူလအတိုင်း ပြန်မထားနိုင်ခြင်း (Revert မရခြင်း)

**ရောဂါလက္ခဏာ** - `mtc session revert` မအောင်မြင်ပါ သို့မဟုတ် ဖိုင်ကို မူလအတိုင်း ပြန်မရောက်စေပါ။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Patch ဖိုင် ပျောက်ဆုံးနေခြင်း** - Session ၏ Patch data များ ဖျက်ဆီးခံလိုက်ရခြင်း ဖြစ်နိုင်သည်။
2. **ပြင်ပမှ ဖိုင်ကို ပြင်ဆင်လိုက်ခြင်း** - ဖိုင်ကို Session ၏ ပြင်ပမှ ပြောင်းလဲလိုက်ပါက ဖြစ်တတ်သည်။

## Daemon ဆိုင်ရာ ပြဿနာများ (Daemon Issues)

### Daemon သို့ Webhooks များ ရောက်မလာခြင်း

**ရောဂါလက္ခဏာ** - GitHub/GitLab webhooks များက Daemon ကို စတင်မလုပ်ဆောင်ပေးနိုင်ပါ။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Port ကို ဝင်ရောက်၍ မရပါ** - Daemon port ပွင့်နေကြောင်းနှင့် Firewall မှ ပိတ်မထားကြောင်း သေချာပါစေ။
2. **Webhook URL မှားယွင်းနေခြင်း** - GitHub/GitLab ပြင်ဆင်ချက်များရှိ Webhook URL ကို စိစစ်ပါ။
3. **Signature စစ်ဆေးမှု မအောင်မြင်ပါ** - `MTC_WEBHOOK_SECRET` သည် Webhook secret နှင့် ကိုက်ညီမှု ရှိမရှိ စစ်ဆေးပါ။

### Autofix စီးဆင်းမှု ရပ်တန့်သွားခြင်း သို့မဟုတ် မအောင်မြင်ခြင်း

**ရောဂါလက္ခဏာ** - Daemon စတင်သော်လည်း Autofix စီးဆင်းမှု မပြီးမြောက်ပါ။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Git clone မအောင်မြင်ပါ** - `MTC_GITHUB_TOKEN` တွင် Repo access ရှိမရှိ စစ်ဆေးပါ။
2. **LLM ခေါ်ယူမှု မအောင်မြင်ပါ** - Provider ပြင်ဆင်ချက်များနှင့် API keys များကို စစ်ဆေးပါ။
3. **Tests များ မအောင်မြင်ပါ** - ပြင်ဆင်ချက်ကြောင့် ရှိပြီးသား Tests များ ပျက်စီးသွားခြင်း ဖြစ်နိုင်သည်။
4. **Push မအောင်မြင်ပါ** - Token တွင် Repo သို့ Write access ရှိကြောင်း သေချာပါစေ။

## VS Code Extension ဆိုင်ရာ ပြဿနာများ (VS Code Extension Issues)

### Extension က Server သို့ မချိတ်ဆက်နိုင်ခြင်း

**ရောဂါလက္ခဏာ** - Extension မှ "Connection failed" သို့မဟုတ် "Disconnected" ဟု ပြသနေခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Server ကို Run ထားခြင်း မရှိပါ** - မချိတ်ဆက်မီ `mtc serve` ကို စတင်ပါ။
2. **Port သို့မဟုတ် Token မှားယွင်းနေခြင်း** - `-p` နှင့် `-t` flags များသည် Extension ပြင်ဆင်ချက်များနှင့် ကိုက်ညီမှု ရှိမရှိ စိစစ်ပါ။
3. **Firewall မှ ပိတ်ထားခြင်း** - WebSocket port ကို ဝင်ရောက် အသုံးပြုနိုင်ကြောင်း သေချာပါစေ။

### Extension ဘေးဘောင် (Sidebar) ဗလာဖြစ်နေခြင်း

**ရောဂါလက္ခဏာ** - Sidebar webview က တက်လာသော်လည်း အကြောင်းအရာများ ပြသခြင်း မရှိပါ။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **Active session မရှိပါ** - TUI တွင် သို့မဟုတ် Extension မှတစ်ဆင့် စကားပြောဆိုမှုတစ်ခု စတင်ပါ။
2. **WebSocket ချိတ်ဆက်မှု ပြတ်တောက်သွားခြင်း** - Extension command palette မှ ပြန်လည် ချိတ်ဆက်ပါ။

## စွမ်းဆောင်ရည်ဆိုင်ရာ ပြဿနာများ (Performance Issues)

### Agent စက်ဝန်း နှေးကွေးနေခြင်း

**ရောဂါလက္ခဏာ** - Agent ၏ အလှည့်တစ်ခုစီသည် ကြာမြင့်လွန်းနေခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **LLM latency** - ပိုမိုမြန်ဆန်သော Model သို့မဟုတ် Provider သို့ ပြောင်းလဲပါ။
2. **Tools ပမာဏ များပြားလွန်းခြင်း** - မှတ်ပုံတင်ထားသော Tools ပမာဏကို လျှော့ချပါ။
3. **Context ကြီးမားနေခြင်း** - စကားပြော မှတ်တမ်းကို တိုတောင်းစေရန် ပြုလုပ်ပါ သို့မဟုတ် Summarization ကို ဖွင့်ပါ။
4. **ကွန်ရက် နှောင့်နှေးမှု** - ပထဝီဝင်အနေအထားအရ ပိုမိုနီးကပ်သော LLM endpoint ကို အသုံးပြုပါ။

### Memory အသုံးပြုမှု မြင့်မားနေခြင်း

**ရောဂါလက္ခဏာ** - `mtc` က RAM အမြောက်အမြား သုံးစွဲနေခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **စကားပြော မှတ်တမ်း ကြီးမားနေခြင်း** - Auto-summarization ကို ဖွင့်ထားပါ။
2. **MCP servers မှ Memory လိမ့်ထွက်နေခြင်း (Leaking)** - MCP processes များကို ရှင်းလင်းရန် `mtc` ကို ပြန်စတင်ပါ။
3. **Session database ကြီးထွားလာခြင်း** - Session ဟောင်းများကို ရှင်းလင်းပါ။

## Build နှင့် ဖွံ့ဖြိုးတိုးတက်ရေးဆိုင်ရာ ပြဿနာများ (Build and Development Issues)

### `bun run build` မအောင်မြင်ခြင်း

**ရောဂါလက္ခဏာ** - Build command က Errors များ ထွက်ပေါ်စေခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **TypeScript အမှားများ** - သီးသန့် အမှားများကို ကြည့်ရှုရန် `bun run typecheck` ကို Run ပါ။
2. **Dependencies များ မရှိပါ** - `bun install` ကို Run ပါ။
3. **မကိုက်ညီသော Bun ဗားရှင်း** - Bun >= 1.2.0 ရှိကြောင်း သေချာပါစေ။

### Tests များ မအောင်မြင်ခြင်း

**ရောဂါလက္ခဏာ** - `bun test` က မအောင်မြင်သော Tests များကို ထုတ်ပေးခြင်း။

**အကြောင်းရင်းများနှင့် ဖြေရှင်းနည်းများ** -

1. **မတည်ငြိမ်သော (Flaky) Tests များ** - ပြန်လည် Run ပါ၊ အချို့ Tests များသည် ကွန်ရက် သို့မဟုတ် အချိန်ကိုက်မှုပေါ် မူတည်ပါသည်။
2. **Test data မရှိပါ** - Test fixtures များ ရှိကြောင်း သေချာပါစေ။
3. **Environment variables** - အချို့ Tests များသည် `MTC_LICENSE_SECRET` သို့မဟုတ် အခြား Env vars များ လိုအပ်ပါသည်။

## အခြေအနေကို မည်သို့ စစ်ဆေးမလဲ (How to Inspect State)

### လက်ရှိ ပြင်ဆင်ချက်များကို ကြည့်ရှုရန်

```bash
mtc llm status
mtc debug info

```

### Session မှတ်တမ်းကို ကြည့်ရှုရန်

```bash
mtc session list -n 20

```

### Agent ခွင့်ပြုချက်များကို ကြည့်ရှုရန်

```bash
cat .mtc/agents/*.md
cat ~/.config/mtc/agents/*.md

```

### SQLite sessions database ကို စစ်ဆေးရန်

```bash
sqlite3 ~/.config/mtc/sessions.db "SELECT * FROM sessions LIMIT 10;"

```

### MCP server အခြေအနေကို စစ်ဆေးရန်

```bash
/mcps   # TUI အတွင်း
cat .mtc/mcp.json
cat ~/.config/mtc/mcp.json

```
