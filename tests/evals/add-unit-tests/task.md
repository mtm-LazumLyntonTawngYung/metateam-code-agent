# Add Unit Tests

Write a comprehensive test suite for the provided utility functions.
Use Node's built-in `assert` module (no external test framework needed).

## Requirements

- Create a file called `test.js` in the sandbox root
- Test all functions exported from `utils.js`:
  - `isPalindrome(str)`
  - `factorial(n)`
  - `fibonacci(n)`
- Cover edge cases: empty strings, zero, negative numbers, large inputs
- All tests must pass when run with `node test.js`
- Do NOT modify `utils.js`
