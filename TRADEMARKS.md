## Usage Guidelines

1. **Always use marks as adjectives**, never as nouns or verbs.
   - ✅ "the Metateam Code Agent CLI"
   - ❌ "install Metateam Code Agent" (instead: "install the Metateam Code Agent CLI")
2. **Mark the first or most prominent use** with the appropriate symbol:
   - ® for registered marks (once registration issues)
   - ™ for unregistered marks (common-law)
3. **Do not alter, abbreviate, or combine** marks — e.g., write "mtc audit"
   not "mtc-audit" as a product name.
4. **Include a trademark attribution notice** in documentation and
   packaging: *"Metateam Code Agent and mtc are trademarks of MetaTeam
   Technologies."*

## Prohibited Uses

- Using marks in a way that implies endorsement or partnership without
  written agreement
- Registering marks or confusingly similar terms as domain names,
  social media handles, or app store listings
- Using marks in false or misleading advertising
