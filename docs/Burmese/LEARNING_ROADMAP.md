# Learning Roadmap (မြန်မာ)

MetaTeam Code Agent ကို လေ့လာရန်အတွက် ၆ ပတ်ကြာ လမ်းညွှန်သင်ရိုး ဖြစ်သည်။ အပတ်တစ်ခုစီသည် ရှေ့အပတ်များပေါ်တွင် အခြေခံ၍ လေ့လာသွားရန် ပြင်ဆင်ထားခြင်း ဖြစ်သည်။ အပတ်စဉ် လုပ်ဆောင်ချက်များနှင့်အတူ `docs/EXERCISES.md` တွင်ရှိသော လေ့ကျင့်ခန်းများကို ပူးတွဲ လုပ်ဆောင်ပါ။

# Learning Roadmap (အင်္ဂလိပ် အညွှန်း)

---

## ကြိုတင် လိုအပ်ချက်များ (Prerequisites)

မစတင်မီ မိမိအနေဖြင့် အောက်ပါတို့နှင့် အကျွမ်းတဝင်ရှိစေရန် သေချာပါစေ -

* TypeScript အခြေခံများ (Types, functions, async/await)
* Terminal/command line အသုံးပြုမှု
* အခြေခံ HTTP နှင့် WebSocket သဘောတရားများ
* Git အခြေခံများ (Clone, branch, commit, push)
* Bun runtime နှင့် package စီမံခန့်ခွဲမှု

---

## အပတ်စဉ် (၁) - စတင် မိတ်ဆက်ခြင်းနှင့် တပ်ဆင်ခြင်း (Orientation and Setup)

**ရည်မှန်းချက်** - Project ကို စတင် Run နိုင်ရန်နှင့် ပင်မ အယူအဆအကြောင်းအရာ အပြည့်အစုံကို နားလည်စေရန်။

### နေ့စဉ် (၁-၂) - ပတ်ဝန်းကျင် တပ်ဆင်ခြင်း (Environment Setup)

* Bun နှင့် CLI ကို တပ်ဆင်ရန် `docs/BEFORE_YOU_START.md` ကို လိုက်နာပါ။
* Source code မှတစ်ဆင့် `bun install && bun run build` ဖြင့် တည်ဆောက်ပါ။
* `mtc --version` အလုပ်လုပ်ပုံကို စစ်ဆေးပါ။
* TUI ကို စတင်ပြီး တိကျစွာ Render ဖြစ်မဖြစ် အတည်ပြုပါ။

### နေ့စဉ် (၃-၄) - Architecture အကျဉ်းချုပ် (Architecture Overview)

* `docs/AGENT_PIPELINE_EXPLAINED.md` ကို ဖတ်ရှုပါ။
* Architecture Diagram တစ်ခုလုံးကို စာရွက်ပေါ်တွင် ရေးဆွဲပါ။
* ပင်မ အစိတ်အပိုင်းများကို ခွဲခြားမှတ်သားပါ။
* TUI Input မှ LLM တုံ့ပြန်ချက်အထိ လုပ်ဆောင်မှုတစ်ခုစီကို အဆင့်လိုက် ခြေရာခံပါ။

### နေ့စဉ် (၅) - ပထမဆုံး Code ဖတ်ရှုခြင်း (First Code Reading)

* `src/cli.tsx` ကို ဖွင့်ပါ။
* `src/ui/App.tsx` ကို ဖွင့်ပါ။
* `src/agents/index.ts` ကို ဖတ်ရှုပါ။

### စစ်ဆေးရမည့် အချက်များ (Checkpoint)

သင်သည် အောက်ပါတို့ကို ရှင်းပြနိုင်ရမည် -

* MetaTeam Code Agent သည် မည်သည့်အရာဖြစ်ကြောင်း စာကြောင်း ၂-၃ ကြောင်းဖြင့် ရှင်းပြနိုင်ခြင်း
* TUI, daemon နှင့် server modes များအကြား ကွာခြားချက်
* လုပ်ဆောင်မှု စက်ဝန်းအတွင်း Agent တစ်ခု၊ Tool တစ်ခုနှင့် LLM တို့ ချိတ်ဆက် ဆောင်ရွက်ပုံ

---

## အပတ်စဉ် (၂) - Agents နှင့် ခွင့်ပြုချက်များ (Agents and Permissions)

**ရည်မှန်းချက်** - Agents များ အလုပ်လုပ်ပုံနှင့် ခွင့်ပြုချက်များမှ ၎င်းတို့၏ ပြုမူဆောင်ရွက်ပုံကို မည်သို့ ထိန်းချုပ်ကြောင်း နားလည်စေရန်။

### လေ့လာရမည့် အကြောင်းအရာများ (Topics)

* Agent သတ်မှတ်ချက်များ (System prompts, permissions)
* Built-in vs Custom agents
* ခွင့်ပြုချက် အဆင့်များ (`allow`, `ask`, `deny`)
* TUI အတွင်း Agent ပြောင်းလဲ အသုံးပြုခြင်း
* Rules နှင့် Frontmatter

### လုပ်ဆောင်ရန် လုပ်ငန်းစဉ်များ (Tasks)

1. `docs/CODE_WALKTHROUGH.md` ပါ `src/agents/` နှင့် `src/tools/` အပိုင်းများကို ဖတ်ရှုပါ။
2. `docs/EXERCISES.md` ပါ **လေ့ကျင့်ခန်း ၁ နှင့် ၂** ကို ပြီးမြောက်အောင် လုပ်ဆောင်ပါ။
3. စမ်းသပ်မှု - မတူညီသော ခွင့်ပြုချက် သတ်မှတ်ချက်များပါရှိသည့် Agents ၃ ခုကို ဖန်တီးပါ။
4. လုပ်ငန်းစဉ်တစ်ခုတည်းပေါ်တွင် Agent တစ်ခုစီကို စမ်းသပ်ပြီး ပြုမူဆောင်ရွက်ပုံများကို နှိုင်းယှဉ်ပါ။

### စစ်ဆေးရမည့် အချက်များ (Checkpoint)

သင်သည် အောက်ပါတို့ကို လုပ်ဆောင်နိုင်ရမည် -

* Agent ဆိုသည်မှာ မည်သည့်အရာဖြစ်ကြောင်းနှင့် ၎င်း၏ System prompt က မည်သည့်အရာများကို ထိန်းချုပ်ထားကြောင်း ရှင်းပြနိုင်ခြင်း
* ခွင့်ပြုချက် အဆင့် ၄ ဆင့်ကို ဖော်ပြနိုင်ခြင်း
* Markdown ဖိုင်မှတစ်ဆင့် Custom agent တစ်ခု ဖန်တီးနိုင်ခြင်း

---

## အပတ်စဉ် (၃) - Tools နှင့် Plugins များ (Tools and Plugins)

**ရည်မှန်းချက်** - Tools များက Agent ၏ စွမ်းဆောင်ရည်များကို မည်သို့ တိုးချဲ့ပေးကြောင်း နားလည်စေရန်။

### လေ့လာရမည့် အကြောင်းအရာများ (Topics)

* Built-in tools များ (File, bash, websearch, git, စသည်)
* Input စစ်ဆေးအတည်ပြုရန် Zod schemas များ
* Tool မလုပ်ဆောင်မီ ခွင့်ပြုချက်များ စစ်ဆေးခြင်း
* Plugin စနစ်နှင့် စက်တွင်း Tool သတ်မှတ် မှတ်ပုံတင်ခြင်း
* ပြင်ပ Tools များအတွက် MCP ချိတ်ဆက် ဆောင်ရွက်ခြင်း

### လုပ်ဆောင်ရန် လုပ်ငန်းစဉ်များ (Tasks)

1. `docs/CODE_WALKTHROUGH.md` ပါ `src/tools/` အပိုင်းကို ဖတ်ရှုပါ။
2. `docs/EXERCISES.md` ပါ **လေ့ကျင့်ခန်း ၃** ကို ပြီးမြောက်အောင် လုပ်ဆောင်ပါ။
3. `src/plugins/index.ts` နှင့် `examples/plugins/hello.ts` တို့ကို လေ့လာပါ။
4. စိတ်ကြိုက် Tool တစ်ခု သတ်မှတ်နိုင်သည့် ရိုးရှင်းသော Plugin တစ်ခု ဖန်တီးပါ။

### စစ်ဆေးရမည့် အချက်များ (Checkpoint)

သင်သည် အောက်ပါတို့ကို လုပ်ဆောင်နိုင်ရမည် -

* Built-in tools ၁၂ ခုထက်မကကို စာရင်းပြုစုပြီး တစ်ခုစီ၏ လုပ်ဆောင်ချက်ကို ဖော်ပြနိုင်ခြင်း
* Zod schemas များက Tool inputs များကို မည်သို့ စစ်ဆေးအတည်ပြုကြောင်း ရှင်းပြနိုင်ခြင်း
* သတ်မှတ်မှတ်တမ်း (Registry) ထဲသို့ Tool အသစ်တစ်ခု ပေါင်းထည့်နိုင်ခြင်း

---

## အပတ်စဉ် (၄) - LLM Providers နှင့် လမ်းကြောင်းသတ်မှတ်ခြင်း (LLM Providers and Routing)

**ရည်မှန်းချက်** - Agent က LLMs များကို မည်သို့ ချိတ်ဆက် အသုံးပြုကြောင်း နားလည်စေရန်။

### လေ့လာရမည့် အကြောင်းအရာများ (Topics)

* Provider ပေါင်းစပ်ဖွဲ့စည်းမှု (DeepSeek, OpenAI, Anthropic, OpenRouter, llama.cpp)
* လုပ်ငန်းစဉ် ခွဲခြားခြင်းနှင့် Model လမ်းကြောင်းသတ်မှတ်ခြင်း
* စနစ် ကြံ့ခိုင်မှုအတွက် အစားထိုး အသုံးပြုမှု စနစ်များ (Fallback chains)
* တုံ့ပြန်ချက်များကို တိုက်ရိုက် ထုတ်လွှင့်ခြင်း (Streaming responses)
* Token အသုံးပြုမှုနှင့် ကုန်ကျစရိတ် စီမံခန့်ခွဲခြင်း

### လုပ်ဆောင်ရန် လုပ်ငန်းစဉ်များ (Tasks)

1. `docs/CODE_WALKTHROUGH.md` ပါ `src/llm/` အပိုင်းကို ဖတ်ရှုပါ။
2. `docs/EXERCISES.md` ပါ **လေ့ကျင့်ခန်း ၄၊ ၅ နှင့် ၆** ကို ပြီးမြောက်အောင် လုပ်ဆောင်ပါ။
3. Providers ၂ ခုကို ပြင်ဆင်သတ်မှတ်ပြီး တုံ့ပြန်မှု အရည်အသွေးနှင့် ကြာချိန်တို့ကို နှိုင်းယှဉ်ပါ။
4. လမ်းကြောင်း သတ်မှတ်ချက် ဆုံးဖြတ်ချက်များကို ကြည့်ရှုနိုင်ရန် ယာယီ Logging ကို ပေါင်းထည့်ပါ။

### စစ်ဆေးရမည့် အချက်များ (Checkpoint)

သင်သည် အောက်ပါတို့ကို လုပ်ဆောင်နိုင်ရမည် -

* လမ်းကြောင်းသတ်မှတ်မှု အဆင့် ၃ ဆင့်ကို ရှင်းပြနိုင်ခြင်း (Simple, default, reasoning)
* CLI မှတစ်ဆင့် LLM Provider အသစ်တစ်ခု ပြင်ဆင်သတ်မှတ်နိုင်ခြင်း
* Fallback chains များ မည်သည့်အတွက် ကြောင့် အရေးပါသည်ကို ရှင်းပြနိုင်ခြင်း

## အပတ်စဉ် (၅) - Sessions, MCP နှင့် ပူးပေါင်းဆောင်ရွက်ခြင်း (Sessions, MCP, and Collaboration)

**ရည်မှန်းချက်** - အခြေအနေ စီမံခန့်ခွဲမှု (State management)၊ ပြင်ပ Tool ချိတ်ဆက်မှုနှင့် အသုံးပြုသူ အများအပြား ထောက်ပံ့မှုစနစ်တို့ကို နားလည်စေရန်။

### လေ့လာရမည့် အကြောင်းအရာများ (Topics)

* Session အမြဲတမ်း သိမ်းဆည်းထားမှု (SQLite)
* စကားပြော မှတ်တမ်းနှင့် File patches များ
* MCP server ရှာဖွေတွေ့ရှိမှုနှင့် Tool သတ်မှတ် မှတ်ပုံတင်ခြင်း
* Shared sessions နှင့် Real-time ပူးပေါင်းဆောင်ရွက်မှု
* WebSocket မှတစ်ဆင့် VS Code extension ချိတ်ဆက်ခြင်း

### လုပ်ဆောင်ရန် လုပ်ငန်းစဉ်များ (Tasks)

1. `docs/CODE_WALKTHROUGH.md` ပါ `src/session/`, `src/mcp/`, `src/shared-sessions/` နှင့် `src/server/` အပိုင်းများကို ဖတ်ရှုပါ။
2. `docs/EXERCISES.md` ပါ **လေ့ကျင့်ခန်း ၇၊ ၈ နှင့် ၁၀** ကို ပြီးမြောက်အောင် လုပ်ဆောင်ပါ။
3. VS Code extension ကို `mtc serve` သို့ ချိတ်ဆက်ပြီး TUI နှင့် နှိုင်းယှဉ်ပါ။
4. Shared session တစ်ခုကို စတင်ပြီး ပူးပေါင်းဆောင်ရွက်မှု အင်္ဂါရပ်များကို စမ်းသပ်ပါ။

### စစ်ဆေးရမည့် အချက်များ (Checkpoint)

သင်သည် အောက်ပါတို့ကို လုပ်ဆောင်နိုင်ရမည် -

* Session တစ်ခုက မည်သည့်အရာများကို သိမ်းဆည်းကြောင်းနှင့် ၎င်းကို မည်သို့ အမြဲတမ်း သိမ်းဆည်းထားကြောင်း ရှင်းပြနိုင်ခြင်း
* MCP server တစ်ခုကို ပြင်ဆင်သတ်မှတ်ပြီး ၎င်း၏ Tools များ ပေါ်ထွက်လာမှု ရှိမရှိ စစ်ဆေးနိုင်ခြင်း
* Extension နှင့် Server အကြား WebSocket protocol လုပ်ဆောင်ပုံကို ဖော်ပြနိုင်ခြင်း

## အပတ်စဉ် (၆) - Daemon, Enterprise နှင့် အဆင့်မြင့် အကြောင်းအရာများ (Daemon, Enterprise, and Advanced Topics)

**ရည်မှန်းချက်** - Headless လုပ်ဆောင်မှု၊ Enterprise အင်္ဂါရပ်များနှင့် Production ဆိုင်ရာ လိုအပ်ချက်များကို နားလည်စေရန်။

### လေ့လာရမည့် အကြောင်းအရာများ (Topics)

* Webhook daemon (GitHub/GitLab)
* Autofix စီးဆင်းမှု (Clone → Analyze → Fix → Test → Push → PR)
* Enterprise အင်္ဂါရပ်များ (Licensing, SSO, RBAC, audit, dashboard)
* လုံခြုံရေး အလေ့အကျင့်များ (Webhook validation, path traversal, secret redaction)
* အကဲဖြတ်ခြင်းနှင့် စံချိန်စံညွှန်း တိုင်းတာခြင်း (Evaluation and benchmarking)

### လုပ်ဆောင်ရန် လုပ်ငန်းစဉ်များ (Tasks)

1. `docs/CODE_WALKTHROUGH.md` ပါ `src/daemon/`, `src/enterprise/` နှင့် `src/review/` အပိုင်းများကို ဖတ်ရှုပါ။
2. `docs/EXERCISES.md` ပါ **လေ့ကျင့်ခန်း ၉၊ ၁၁ နှင့် ၁၂** ကို ပြီးမြောက်အောင် လုပ်ဆောင်ပါ။
3. `mtc eval bench` ကို Run ပြီး ရလဒ်များကို သုံးသပ်ပါ။
4. `docs/EXTENDING_THE_PROJECT.md` ကို ဖတ်ရှုပြီး စမ်းသပ် တည်ဆောက်ရန် အင်္ဂါရပ်တစ်ခု ရွေးချယ်ပါ။

### စစ်ဆေးရမည့် အချက်များ (Checkpoint)

သင်သည် အောက်ပါတို့ကို လုပ်ဆောင်နိုင်ရမည် -

* Daemon မှ Webhooks များကို မည်သို့ လက်ခံ ပြုပြင်ဆောင်ရွက်ကြောင်း ရှင်းပြနိုင်ခြင်း
* Autofix အဆင့်များကို ဖော်ပြနိုင်ခြင်း
* Enterprise licensing နှင့် Tier gating တို့ကို ရှင်းပြနိုင်ခြင်း
* စီမံကိန်းပါ လုံခြုံရေး စနစ် အနည်းဆုံး ၃ ခုကို စာရင်းပြနိုင်ခြင်း

## နောက်ဆုံး အကဲဖြတ်ခြင်း (Final Assessment)

၆ ပတ်လုံး ပြီးမြောက်ပြီးနောက် သင်သည် မှတ်တမ်းများကို ကြည့်ရှုရန် မလိုဘဲ အောက်ပါ မေးခွန်းများကို ဖြေဆိုနိုင်ရမည် -

1. Agentic coding assistant ဆိုသည်မှာ မည်သည့်အရာဖြစ်ပြီး စကားပြော ရိုးရိုး Chatbot နှင့် မည်သို့ ကွာခြားသနည်း။
2. အသုံးပြုသူ Input မှတစ်ဆင့် Tool အကောင်အထည်ဖော်မှု၊ ထိုမှတစ်ဆင့် LLM တုံ့ပြန်ချက်အထိ စက်ဝန်းတစ်ခုလုံးကို အဆင့်လိုက် ရှင်းပြပါ။
3. ခွင့်ပြုချက်များက Agent လုပ်ဆောင်နိုင်သည်များကို မည်သို့ ကန့်သတ်ပေးသနည်း၊ ၎င်းသည် မည်သည့်အတွက်ကြောင့် အရေးပါသနည်း။
4. Built-in tool, MCP tool နှင့် Plugin tool တို့၏ ကွာခြားချက်မှာ မည်သည်နည်း။
5. LLM router က ပေးထားသော Query တစ်ခုအတွက် မည်သည့် Model အသုံးပြုရမည်ကို မည်သို့ ဆုံးဖြတ်သနည်း။
6. Daemon ၏ ရည်ရွယ်ချက်မှာ မည်သည်နည်း၊ Autofix စီးဆင်းမှုက မည်သို့ အလုပ်လုပ်သနည်း။
7. VS Code extension က Agent နှင့် မည်သို့ ဆက်သွယ်သနည်း။
8. Webhook spoofing နှင့် Path traversal တို့ကို မည်သည့် လုံခြုံရေး စနစ်များဖြင့် ကာကွယ်ထားသနည်း။
9. LLM provider အသစ်တစ်ခုအတွက် ထောက်ပံ့မှု ပေါင်းထည့်မည်ဆိုပါက မည်သို့ ဆောင်ရွက်မည်နည်း။
10. တစ်ပြိုင်နက်တည်း အသုံးပြုသော Agent sessions ပမာဏ ၁၀,၀၀၀ ကို ထောက်ပံ့ပေးရန် လိုအပ်ပါက မည်သည့်အရာများကို ပြောင်းလဲဆောင်ရွက်မည်နည်း။

သတ်မှတ်ထားသော လမ်းညွှန်ချိန်ထက် စော၍ ပြီးစီးသွားပါက -
